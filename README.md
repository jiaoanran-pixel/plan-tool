# 车辆计划统计与对账系统

手机端 + 电脑端均可使用的车辆计划登记与对账工具。支持手动录入、微信文本粘贴自动识别、单据照片 OCR 自动匹配，一键导出带图片的 Excel 对账表。

## 功能

- **计划卡片**：装车日期、车号、气源地、供应商、站点、计划到站日期（日期+时间）、价格、净重、金额，以及装车磅单 / 卸车磅单 / 运单三张图片位；支持增删改查、按日期/关键词筛选（默认筛选当天）。
- **一键复制**：每张卡片可一键复制关键文本信息（装车日期、车号、站点、价格、净重、单据状态等），直接粘贴到微信同步给其他人。
- **备注一键清除**：编辑计划时，备注框旁有"一键清除"按钮。
- **剪贴板识别**：把微信里复制的计划文本粘贴进来，自动填表（已按常见格式适配，可再定制）。
- **OCR 自动匹配**：上传单据照片后自动识别文字，判断单据类型（装车磅单/卸车磅单/运单），按「装车日期 + 车号」匹配计划并自动填入图片位；卸车磅单自动提取净重并计算金额（价格 × 净重）。识别失败时提示并允许手动关联。
- **每日/每月对账**：按车数、资料齐全数、缺单数、金额合计统计；每日清单卡片展示，月度按天汇总。
- **Excel 导出**：按截图模板导出（气源地、装车日期、车号、供应商、站点、计划到站日期、价格、装车磅单、卸车磅单、运单、净重、金额、备注），磅单/运单图片直接嵌入表格，附"每日汇总"表与合计行。

## 快速开始

需要 macOS（OCR 使用系统自带 Vision 框架）。

```bash
# 1. 编译 OCR 辅助程序（首次）
./build_ocr.sh

# 2. 启动服务
python3 server.py
```

依赖：Python 3.8+、openpyxl、Pillow（用于 Excel 嵌入图片）：

```bash
python3 -m pip install openpyxl pillow
```

启动后：

- 本机浏览器打开 http://127.0.0.1:8766
- 手机与电脑连同一 Wi-Fi，浏览器打开 http://<电脑局域网IP>:8766
- 查看本机 IP：`ipconfig getifaddr en0`

## 使用说明

### 新增计划（三种方式）

1. 点右上角"新增计划"，手动填写后保存；
2. 在弹窗里粘贴微信复制的计划文本，点"识别填充"自动填表，核对后保存；
3. 点"识别上传"，直接拍照/选择单据图片，系统自动识别并匹配已有计划，确认后自动填入。

### 图片归集

- 编辑卡片时，三个图片位可分别拍照/上传；
- 或在列表页用"识别上传"统一处理：OCR → 类型判断 → 按车号+日期匹配 → 确认填入。

### 对账与导出

- "对账"页支持每日 / 每月切换；
- 选好日期范围后点"导出 Excel"，浏览器会下载 .xlsx 文件，图片已嵌入。

## 目录结构

```text

ocr_helper.m          macOS Vision OCR 辅助程序源码
build_ocr.sh          OCR 编译脚本
static/               前端页面（index.html / app.js / style.css）
data/                 运行数据（SQLite + 单据图片，自动生成，勿手动改）
tests/                接口测试脚本与样本
tools/xlsx_verify/    Excel 导出校验工具
车辆计划对账系统_需求文档.md  需求文档
```

如需一个手机、电脑点开即用的固定网址，可使用 `static-site/` 目录部署为静态网站（GitHub Pages / Netlify Drop / Cloudflare Pages 等均可）。

- ✅ 当前线上地址：**https://jiaoanran-pixel.github.io/plan-tool/**

- 部署步骤与数据说明见 [static-site/部署说明.md](static-site/部署说明.md)；
- 注意：静态版数据保存在各设备浏览器中，**多设备不自动同步**，请定期"导出 Excel"备份；
- 静态版 OCR 使用浏览器端识别（首次下载约 15MB 中文包、速度较慢）；本地版 OCR 更快更准，适合局域网内使用。

## 常见问题

- **OCR 识别失败/不准**：照片模糊、倾斜、反光会影响识别；类型判断和净重提取失败时，页面上会提示"自动识别失败"，可手动选择单据类型并关联计划，或手动填净重。
- **磅单上没有车号或日期**：无法自动匹配，需手动关联到计划。
- **手机在外面不能用**：当前为局域网访问；如需外网使用，可后续用内网穿透（如 Tailscale / Cloudflare Tunnel）或部署到云服务器。
- **自动接收微信里的图片**：微信个人号无开放接口，需手动把图片保存后上传。
- **数据备份**：整个 `data/` 目录就是全部数据，拷贝即备份。

## 技术说明

- 服务端：Python 标准库 HTTP 服务 + SQLite，无框架依赖；
- OCR：macOS Vision 框架（中文识别，免费离线），由 Python 调用编译后的 `ocr_helper`；
- Excel：openpyxl 生成 .xlsx，图片直接嵌入；
- 前端：原生 HTML/CSS/JS 响应式页面，手机、电脑通用。
