# 静态版部署说明（在线链接）

把 `static-site` 目录里的文件部署到静态网站托管平台，手机和电脑打开网址即可使用，无需安装任何东西。

> ✅ 当前已部署：
> - **腾讯云 CloudBase（国内可直连，日常使用）：** https://plan-tool-d6go558kq997baafd-1467420101.tcloudbaseapp.com/plan-tool/
> - **GitHub Pages（备用）：** https://jiaoanran-pixel.github.io/plan-tool/

## 一、腾讯云 CloudBase（国内可直连，推荐）

1. 打开 https://console.cloud.tencent.com/tcb ，用微信扫码登录（首次需完成个人实名认证）；
2. 点「新建环境」，环境名称填 `plan-tool`，计费方式选**免费体验版**（0 元/月，每月 3000 资源点，足够本网站使用）；
3. 左侧菜单进入「静态网站托管」→「网站部署」→ 选**本地项目部署** →「上传代码包」；
4. 上传 [plan-tool-cloudbase.zip](../plan-tool-cloudbase.zip)（或把 `static-site/` 里的文件打成一个 zip 上传）；
5. 部署成功后访问：`https://<环境ID>.tcloudbaseapp.com/plan-tool/`（注意末尾带 `/plan-tool/`）。

> ⚠️ **免费体验版每 6 个月需续期一次**：到期前 1 个月内，在云开发控制台「环境管理」里点一次「续费」，可再免费续 6 个月（不支持自动续费，请留意到期提醒）。
>
> 首次访问默认域名时，腾讯云可能弹出"访问提示中间页"，点「继续访问」即可进入系统。

### 更新方法

改完功能后，把 `static-site/` 里更新过的文件重新打成 zip，再到「静态网站托管 → 网站部署 → 本地项目部署 → 上传代码包」上传一次即可，链接不变。

## 二、GitHub Pages（备用，国内直连不稳定）

1. 在 GitHub 新建仓库（如 `plan-tool`）；
2. 把 `static-site/` 里的**所有文件**上传到仓库根目录；
3. 仓库 Settings → Pages → Source 选择 `main` 分支，保存；
4. 几分钟后访问 `https://<你的用户名>.github.io/<仓库名>/`。

> 国内网络直连 `github.io` 可能被断开，手机打不开时请使用 CloudBase 链接。

## 三、Netlify Drop（海外备用）

1. 打开 https://app.netlify.com/drop ；
2. 把 `static-site/` 文件夹直接拖进网页；
3. 立即获得一个 `https://xxxx.netlify.app` 网址。

## 数据说明（重要）

- 数据保存在**打开网页的设备浏览器**里（localStorage + IndexedDB）；
- 同一台设备、同一个浏览器，数据永久保留；
- **不同设备之间不自动同步**：手机上录入的数据，电脑上看不到；
- **清除浏览器缓存、换浏览器或换设备会看不到原数据**；
- 请定期在"对账"页点"导出 Excel"备份；也可以每月把 Excel 下载保存一份。

## 与本地版的功能差异

| 功能 | 本地版（python3 server.py） | 静态版（在线链接） |
| --- | --- | --- |
| 计划卡片、粘贴识别、对账、复制 | ✅ | ✅ |
| 图片上传归集 | ✅ | ✅（存在浏览器 IndexedDB） |
| OCR 自动识别 | ✅ macOS Vision（快、准） | ✅ 浏览器 Tesseract.js（首次使用需下载约 15MB 中文包，识别较慢） |
| Excel 导出（图片嵌入） | ✅ | ✅ 浏览器内生成 |
| 数据存放 | 电脑本地 data/ 目录 | 各设备浏览器 |
| 多设备同步 | ❌ | ❌ |

## 本地预览

```bash
cd static-site
python3 -m http.server 8768
# 浏览器打开 http://127.0.0.1:8768
```

> 直接双击 index.html 用 file:// 打开也能用，但部分浏览器对 IndexedDB 有限制，建议用 http 方式访问。
