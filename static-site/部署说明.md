# 静态版部署说明（在线链接）

把 `static-site` 目录里的文件部署到任意静态网站托管平台，手机和电脑打开网址即可使用，无需安装任何东西。

> ✅ 当前已部署：**https://jiaoanran-pixel.github.io/plan-tool/**

## 部署方法（任选其一）

### 1. GitHub Pages（免费，推荐）

1. 在 GitHub 新建一个仓库（如 `plan-tool`）；
2. 把 `static-site/` 里的**所有文件**上传到仓库根目录；
3. 仓库 Settings → Pages → Source 选择 `main` 分支，保存；
4. 几分钟后访问 `https://<你的用户名>.github.io/<仓库名>/`。

### 2. Netlify Drop（免费，最简单）

1. 打开 https://app.netlify.com/drop ；
2. 把 `static-site/` 文件夹直接拖进网页；
3. 立即获得一个 `https://xxxx.netlify.app` 网址。

### 3. Cloudflare Pages / Vercel

- Cloudflare Pages：控制台 → Create project → Direct Upload，把 `static-site/` 拖入。
- Vercel：导入项目，构建命令留空（纯静态），输出目录选根目录。

## 数据说明（重要）

- 数据保存在**打开网页的设备浏览器**里（localStorage + IndexedDB）；
- 同一台设备、同一个浏览器，数据永久保留；
- **不同设备之间不自动同步**：手机上录入的数据，电脑上看不到；
- **清除浏览器缓存、换浏览器或换设备会看不到原数据**；
- 请定期在"对账"页点"导出 Excel"备份；也可以每月把 Excel 下载保存一份。

## 与本地版的功能差异

| 功能 | 本地版（python3 server.py） | 静态版（在线链接） |
| --- | --- | --- |
| 计划卡片、粘贴识别、对账、复制 | ✅ | ✅ |
| 图片上传归集 | ✅ | ✅（存在浏览器 IndexedDB） |
| OCR 自动识别 | ✅ macOS Vision（快、准） | ✅ 浏览器 Tesseract.js（首次使用需下载约 15MB 中文包，识别较慢） |
| Excel 导出（图片嵌入） | ✅ | ✅ 浏览器内生成 |
| 数据存放 | 电脑本地 data/ 目录 | 各设备浏览器 |
| 多设备同步 | ❌ | ❌ |

## 本地预览

```bash
cd static-site
python3 -m http.server 8768
# 浏览器打开 http://127.0.0.1:8768
```

> 直接双击 index.html 用 file:// 打开也能用，但部分浏览器对 IndexedDB 有限制，建议用 http 方式访问。
